PatchCore 一键配置环境说明
==========================

注意：.txt 文件只是说明，真正用于一键配置的是同目录下的脚本。

Windows 使用：

    setup_environment.bat

Linux / Ubuntu 使用：

    setup_environment.sh


Windows 运行方式
----------------

双击 setup_environment.bat，或者在 PowerShell / CMD 中执行：

    .\setup_environment.bat


Linux / Ubuntu 运行方式
-----------------------

进入项目目录后执行：

    bash setup_environment.sh

如果要指定 CUDA 11.8：

    bash setup_environment.sh cu118

如果只需要 CPU 环境：

    bash setup_environment.sh cpu

该脚本会自动完成：

1. 检查 Python 是否可用。
2. 在项目根目录创建虚拟环境 .venv。
3. 激活虚拟环境。
4. 升级 pip、setuptools、wheel。
5. 安装 PyTorch 和 torchvision。
6. 安装 requirements.txt。
7. 安装 requirements_dev.txt。
8. 执行 pip install -e . 安装本项目。
9. 检查 torch、faiss、timm、patchcore 等关键包是否能正常导入。


运行方式
--------

默认自动模式：

    .\setup_environment.bat

默认模式会检测 nvidia-smi：

- 如果检测到 NVIDIA 驱动，会优先尝试安装 CUDA 12.1 版本 PyTorch。
- 如果没有检测到 NVIDIA 驱动，会安装 CPU 版本 PyTorch。


手动指定 PyTorch 版本
---------------------

只安装 CPU 版本：

    .\setup_environment.bat cpu

安装 CUDA 12.1 版本：

    .\setup_environment.bat cu121

安装 CUDA 11.8 版本：

    .\setup_environment.bat cu118


运行后的使用方式
----------------

环境配置完成后，之后每次使用项目前先激活虚拟环境：

    .\.venv\Scripts\Activate.ps1

或者在 CMD 中：

    .venv\Scripts\activate.bat

然后可以运行项目脚本，例如：

    python bin/run_patchcore.py


前置要求
--------

脚本不能自动安装以下内容，需要提前准备：

1. Python 3.8 或更高版本，推荐 Python 3.10 或 3.11。
2. 如果需要 GPU 运行，需要本机已安装 NVIDIA 显卡驱动。
3. 训练或测试所需的数据集，例如 MVTec AD 或整理成 MVTec 风格的自定义数据集。


常见问题
--------

1. 如果 PyTorch CUDA 安装失败：

   先尝试 CPU 环境：

       .\setup_environment.bat cpu

   或根据本机 CUDA/驱动版本选择 cu121 / cu118。

2. 如果 faiss-cpu 安装失败：

   优先确认 Python 版本。推荐使用 Python 3.10 或 3.11。

3. 如果 PowerShell 不允许运行脚本：

   本项目的一键脚本是 .bat 文件，双击或在 CMD 中运行即可，不需要修改 PowerShell 执行策略。
